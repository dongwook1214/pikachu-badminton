# AI vs AI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pick two AI Unlimited AIs on the page (first pick 1P, second 2P) and watch them play.

**Architecture:** Reuse `setArena(p1, p2, seed)` in `badminton/game.js`, which already drives both players by AI and
ignores the keyboard. Add names to the screen when both sides are AI (`p1Brain` set), and an "AI vs AI" button plus
1P/2P picking in the existing mode-picker block.

**Tech Stack:** plain browser JS (one module), Node 22 `node:test`.

**Spec:** `docs/superpowers/specs/2026-11-26-ai-vs-ai-design.md`

## Global Constraints

- No change to AI behavior, `tools/arena.mjs` output, or online play (`node tools/arena.mjs korean cpu` identical before/after).
- Only AI Unlimited AIs are offered in this mode; the same AI may play both sides.
- No commits without asking the user.

## Review Focus

- Switching from AI vs AI to any other mode (AI levels, AI Unlimited, 둘이서, online) gives 1P back to the keyboard.
- Mirror match (same AI both sides): both badges show on one card, the game runs.
- Clicking a list card while in plain AI Unlimited mode still picks a single opponent (unchanged).
- Arena/test harness stubs `document` (returns null / []): UI code must not throw there.
- Long AI names on the title line and win message stay on screen.
