아이폰은 홈 화면에 추가해 주세요

아이폰 사파리는 웹페이지를 전체 화면으로 바꿀 수 없어요. 대신 앱처럼 설치하면 주소창 없이 꽉 찬 화면으로 열려요.

  1. 사파리 아래쪽 공유 버튼(네모에 위쪽 화살표)을 눌러요.
  2. 홈 화면에 추가를 누르고 추가를 눌러요.
  3. 홈 화면에 생긴 배드민턴 아이콘으로 열고, 폰을 가로로 돌려요.
온라인 대전 또는
한 키보드로 둘이 하는 로컬 모드예요.

1P (왼쪽)

이동 / 점프A D / W
기본 공격F
전기 쏘기G
전광석화H (+ W 위 / A·D 앞뒤)
아이언 테일점프 중 F로 셔틀 치기

2P (오른쪽)

이동 / 점프← → / ↑
기본 공격K 또는 Num1
전기 쏘기L 또는 Num2
전광석화; 또는 Num3 (+ 방향키)
아이언 테일점프 중 K로 셔틀 치기

폰: 왼쪽 버튼으로 이동·점프(▲), 오른쪽 버튼으로 공격·전기·전광석화. 화면을 누르면 시작해요. 칠 때 방향: 그냥 = 클리어 · 앞 = 드라이브 · 뒤 = 로브 · ▼ = 드롭. 점프 중에 공격으로 셔틀을 맞히면 스매시. 가로로 돌리면 더 크게 보여요. 온라인 대전은 화면 아래(가로 모드에선 스크롤)에서 방을 만들거나 참가하세요.

기본 공격으로 칠 때 방향: 그냥 = 클리어 · 앞 = 드라이브 · 뒤 = 높은 로브 · 아래(S/↓) = 드롭. 점프한 채로 기본 공격을 셔틀에 맞히면 자동으로 아이언 테일 스매시가 나가요. 11점 먼저 내면 승리. Enter 시작 · Esc 일시정지.

온라인에서는 각자 자기 키보드로 위 두 키 배치 중 편한 걸 쓰면 돼요. 방장 컴퓨터가 게임을 돌리니, 방장은 이 탭을 계속 앞에 띄워 두세요.
