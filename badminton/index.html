아이폰은 홈 화면에 추가해 주세요

아이폰 사파리는 웹페이지를 전체 화면으로 바꿀 수 없어요. 대신 앱처럼 설치하면 주소창 없이 꽉 찬 화면으로 열려요.

  1. 사파리 아래쪽 공유 버튼(네모에 위쪽 화살표)을 눌러요.
  2. 홈 화면에 추가를 누르고 추가를 눌러요.
  3. 홈 화면에 생긴 배드민턴 아이콘으로 열고, 폰을 가로로 돌려요. 아이폰 듀오는 세로로 들면 위는 게임, 아래는 버튼이에요.

폰: 왼쪽 버튼으로 이동·점프(▲), 오른쪽 버튼으로 공격·전기·전광석화. 화면을 누르면 시작해요. 칠 때 방향: 그냥 = 클리어 · 앞 = 드라이브 · 뒤 = 로브 · ▼ = 드롭. 점프 중에 공격으로 셔틀을 맞히면 스매시. "전체 화면으로 하기"를 누르고 폰을 가로로 돌리면 크게 보여요. 아이폰 듀오처럼 화면이 넓은 폰은 세로로 들면 위는 게임·아래는 버튼이 돼요. 온라인 대전은 화면 아래에서 방을 만들거나 참가하세요.

기본 공격으로 칠 때 방향: 그냥 = 클리어 · 앞 = 드라이브 · 뒤 = 높은 로브 · 아래(S/↓) = 드롭. 점프한 채로 기본 공격을 셔틀에 맞히면 자동으로 아이언 테일 스매시가 나가요. 11점 먼저 내면 승리. Enter 시작 · Esc 일시정지.
